# LidReSleep

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [한국어](./README.ko.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [Español](./README.es.md) | **Русский** | [Português](./README.pt.md) | [Italiano](./README.it.md)

Небольшой фоновый инструмент для Windows, который не даёт ноутбуку нагреваться ночью после закрытия крышки.

Многие современные ноутбуки (Modern Standby) при закрытой крышке на самом деле не засыпают: экран гаснет, но система остаётся подключённой при низком энергопотреблении и может быть легко **разбужена и удерживаться в активном состоянии** сетевыми запросами, фоновыми задачами и т. п., что вызывает нагрев и расход батареи всю ночь.

Что делает LidReSleep, просто: **сон при закрытии крышки; если система неожиданно проснулась, а крышка всё ещё закрыта, она снова засыпает автоматически, пока вы не откроете крышку.**

- Портативное приложение одним файлом, установка не требуется
- 10 языков интерфейса (简体中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Русский / Português / Italiano), определяется автоматически по языку системы
- Windows 10/11 (x64 / ARM64 / x86), выберите версию под ваш процессор

![Скриншот LidReSleep](screenshot.jpg)

## Быстрый старт

1. Скачайте версию для вашего процессора и дважды щёлкните по ней (например, `LidReSleep-amd64.exe`), чтобы открыть панель.
2. Нажмите **「▶ Запустить охрану」**; статус сменится на `● Охрана активна`.
3. Закройте крышку и всё.

После этого: закрытие крышки → немедленный сон; пробуждение при закрытой крышке → повторный сон через ~3 секунды (по умолчанию); открытие крышки → отмена и нормальная работа.

## Руководство по интерфейсу

### Статус
- `● Остановлено / ● Охрана активна`, показывает, работает ли охрана.
- Кнопка `▶ Запустить охрану / ■ Остановить охрану`, текст меняется в зависимости от состояния.

### Настройки

| Параметр | Описание | По умолчанию |
|---|---|---|
| Задержка сна (мс) | подождать это время после пробуждения перед повторным сном | `3000` |
| ☑ Запуск при входе | запускаться автоматически при входе в Windows (системный уровень, реестр) | Нет |
| ☑ Автоохрана после входа | сразу начать охрану и свернуть в трей | Нет |
| ☑ Сворачивать в трей | скрывать в трее при сворачивании | Да |
| ☑ Закрывать в трей | скрывать в трее вместо выхода при закрытии | Да |

- Изменения **сохраняются автоматически**, ручное сохранение не требуется.
- Запуск при входе применяется сразу (реестр); остальные настройки хранятся в `config.json` рядом с exe.

### Меню
- **Файл**: Выход
- **Инструменты**: Тест сна (заснуть один раз для проверки)
- **Язык**: 10 языков (галочка показывает текущий; применяется немедленно)
- **Справка**: Проверить обновления (проверяет GitHub), Страница проекта, О программе (функции и объяснение Modern Standby)

### Журнал
Каждая строка содержит отметку времени и уровень, показывает события крышки/пробуждения/повторного сна в реальном времени, с автопрокруткой и ограничением 200 КБ.

| Уровень | Значение |
|---|---|
| `INFO` | общая информация |
| `EVENT` | системные события (крышка/сон/пробуждение) |
| `ACTION` | действия программы (планирование/отмена/сон) |
| `ERROR` | ошибка (с причиной) |

### Системный трей
- Скрытие в трей при сворачивании/закрытии (если включено).
- Левый клик по значку: восстановить главное окно; правый клик: Показать главное окно / Выход.

## Частые вопросы

**Почему ноутбук всё ещё нагревается после закрытия крышки?**
Скорее всего, его будит Modern Standby. Используйте Инструменты → Тест сна для проверки; после закрытия крышки при активной охране ищите в журнале `ACTION Выполнение сна`.

**Что такое Modern Standby?**
См. простое объяснение в Справка → О программе.

**Как полностью выйти?**
Правый клик по значку в трее → Выход (если включён параметр «Закрывать в трей», ✕ только сворачивает).

**Запуск при входе не работает?**
Это зависит от текущей учётной записи пользователя; сбои (например, при запуске из ограниченной папки) регистрируются с указанием причины.

## Для продвинутых: уменьшить пробуждения (необязательно)

Инструмент отвечает за «повторный сон после пробуждения». Чтобы уменьшить сами пробуждения, выполните в PowerShell от имени администратора:

```powershell
# отключить таймеры пробуждения
powercfg /setacvalueindex SCHEME_CURRENT SUB_SLEEP 0 0
powercfg /setdcvalueindex SCHEME_CURRENT SUB_SLEEP 0 0
# просмотр источников пробуждения
powercfg /waketimers
powercfg /devicequery wake_armed
# восстановить значения по умолчанию
powercfg /restoredefaultschemes
```
